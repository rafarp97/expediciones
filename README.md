# Expediciones

Cotejo de los documentos de un envío y emisión de la factura y los packing list
al cliente.

La aplicación es el propio `index.html`: un solo archivo, sin servidor ni
dependencias. Todo se procesa en el navegador de quien la abre; **ningún
documento se envía a ningún sitio**.

La plantilla que lleva dentro está en blanco a propósito: tiene el membrete, el
formato y las fórmulas, pero ninguna línea, ningún precio y ningún dato de
ningún envío.
